# Watchcharm Projects

A responsive landing page for a modern watch store, built with **HTML, CSS, and vanilla JavaScript**.

The project focuses on clean design, responsive layouts, and interactive user interface elements.

## Demo

**Live Demo:** https://andrii-mitko.github.io/Watchcharm-Projects/

## Preview

A modern watch store landing page featuring a product catalog, brand presentation, customer reviews, and a contact section.

## Features

- Responsive layout for mobile, tablet, and desktop devices
- Mobile navigation menu
- Interactive product catalog with Show more / Show less functionality
- Product presentation section
- Customer reviews section
- Contact form interface
- Custom SVG icons
- Local Gilroy fonts

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- SVG
- Google Fonts — not required; local Gilroy fonts are used
- Git and GitHub

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Andrii-Mitko/Watchcharm-Projects.git
   ```

2. Open the project folder:

   ```bash
   cd Watchcharm-Projects
   ```

3. Open `index.html` in your browser.

No additional dependencies or build tools are required.

## Notes

The contact form is currently a frontend interface and is not connected to a backend service.
